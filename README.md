# LineageOS 24.0 OTA Repository - Google Pixel 8 Pro (husky)

Repositorio oficial de actualizaciones OTA para **Google Pixel 8 Pro (husky)** ejecutando LineageOS 24.0 (Android 17) con soporte para re-bloqueo de bootloader (AVB personalizado) y endurecimiento de seguridad de GrapheneOS.

## Canales OTA disponibles

- **Stable**: `https://raw.githubusercontent.com/rhythmcreative/lineageos-husky-ota/main/husky-stable.json`
- **Beta**: `https://raw.githubusercontent.com/rhythmcreative/lineageos-husky-ota/main/husky-beta.json`
- **Alpha**: `https://raw.githubusercontent.com/rhythmcreative/lineageos-husky-ota/main/husky-alpha.json`
- **Default**: `https://raw.githubusercontent.com/rhythmcreative/lineageos-husky-ota/main/husky.json`

## Características integradas

- **Plataforma Tensor G3 (zuma)**: Optimizaciones completas para CPU Cortex-X3/A715/A510 y GPU Immortalis-G715.
- **Endurecimiento de seguridad**: Integración de protecciones avanzadas inspiradas en GrapheneOS (Auto-Reboot BFU con Titan M, Scramble PIN, interruptor de red por app, interruptor de sensores de hardware).
- **Firmas AVB personalizadas**: Paquete firmado con claves RSA 4096 propias, permitiendo re-bloquear el bootloader de forma segura con `pkmd.bin`.
